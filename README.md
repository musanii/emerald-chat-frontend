# Emerald Chat UI

A minimalist, high-performance web component and standalone chat client for the **Emerald Chat Engine**. Built with **Vue 3**, **Pinia**, and **Tailwind CSS**.

## 🛠 Tech Stack

- **Framework:** Vue 3 (Composition API `<script setup>`)
- **State Management:** Pinia
- **Styling:** Tailwind CSS v4 (Jungle Green Palette)
- **Build Tool:** Vite

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
